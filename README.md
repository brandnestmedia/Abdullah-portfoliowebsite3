# Abdullah Portfolio Website

## Files
- index.html — page structure and content
- style.css — design, layout and animations
- script.js — cursor, scroll-reveal and interactions

## How to edit
Open the folder in VS Code and edit index.html/style.css/script.js.

### Replace portfolio projects
In `index.html`, find the `.projects` section. Replace the demo project media with your own `<video>` or `<img>`.

Example:
<video src="assets/my-video.mp4" autoplay muted loop playsinline></video>

Put your videos/images inside an `assets` folder.
